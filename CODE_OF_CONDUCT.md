# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Argue about the code,
not about the person writing it.

## What that means here

**Good:**

- "This breaks when the device is offline — here is the case I hit."
- "I do not follow why this is a transaction; could you explain?"
- "I disagree, and here is the trade-off I think you are missing."

**Not good:**

- Personal remarks, dismissiveness, or treating a question as an imposition.
- Harassment of any kind, public or private.
- Sexualised language or imagery; unwelcome attention.
- Publishing anyone's private information.
- Sustained disruption of a discussion.

Nobody has to earn politeness by being competent first. A beginner asking
something answered in the README gets a link and a friendly word, not a sigh.

## Scope

Anywhere this project happens: issues, pull requests, discussions, commit
messages, and anywhere someone is representing the project.

## If something goes wrong

Report it to the maintainer, privately: open a
[security advisory](https://github.com/padovanl/qawk/security/advisories/new)
if you would rather it not be public anywhere — it is the only private channel
this repository has, and it is fine to use it for this.

Reports are read by one person, who will not discuss them beyond what is
needed to deal with them. What happens next is proportionate: usually a quiet
word, sometimes an edit or a lock, and — for anything deliberate or repeated —
a ban.

If the problem is with the maintainer, say so publicly in an issue. A project
with one maintainer has no appeal process, and pretending otherwise would be
worse than admitting it.

## Where this comes from

The substance is the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, rewritten in this project's own words. The obligations are the
same ones.
